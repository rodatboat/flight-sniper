## Build and Run
```bash
docker build -t flight-sniper .
# --rm removes the container once it exits
docker run --rm flight-sniper

# Or
docker compose up -d
```

## Install Deps
```bash
python -m venv .venv
pip install --no-cache-dir -r requirements.txt
```
